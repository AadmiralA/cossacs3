# NavalRamming v6 — эксперимент для одиночной игры

**НЕ ПРОВЕРЕНО В ДВИЖКЕ.** Файлы генератора и места вставки проверены по исходникам, но игру должен запустить тестировщик. Оригинальные reference/ не меняются. Сетевая игра и старые сохранения НЕ поддерживаются.

## Функции

1. Все стандартные водные корабли (галера, фрегат, линейный корабль, шебека, чайка, яхты, транспорт, рыбацкая лодка) разгоняются от 35% до 100% первоначального MoveStep. Штатная максимальная скорость не повышается: исходная настройка всех этих типов — MoveStep=0.03, унаследованная от objects/ref/refunit.prop. Интервал шага после апгрейдов не изменяем.
2. Плавный разгон происходит за ~3.25 единиц игрового времени после начала движения; при остановке скорость для следующего старта сбрасывается к 35%.
3. **В этой версии нет настоящего физического выбега после команды «Стоп»** — движок прекращает движение сразу после режима mmNone. Это реалистичная стилизация разгона, а не полноценная модель импульса.
4. Только **галеры** могут нанести первый экспериментальный таран. Условия: враг, вода, нос на цель (virtual forward dot >0.7), расстояние ≤сумма радиусов+0.5, движется, разгон не меньше 55%.
5. Урон цели через штатную _misc_DoDamage: 8000 × текущая доля скорости с учётом штатной защиты, самоурон: 900 через штатную функцию. Перезарядка на атакующую галеру: 5 единиц игрового времени. В логе: NavalRamming HIT.

## Запуск и установка

Открой Git Bash в D:/Work/Cossacs3-mod/cossacs3:

    git fetch origin
    git switch feature/naval-ram-experimental
    git pull --ff-only origin feature/naval-ram-experimental
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./tools/build_experimental_naval_v6.ps1

Получатся **три** файла:
- mod/data/scripts/dmscript.global
- mod/data/scripts/units/unit.inc/initial.inc
- mod/data/scripts/units/unit.inc/nothing.inc

Установи файлы в активный мод с сохранением структуры. Пример:

    Cossacks 3/mods/NavalRamming/data/scripts/dmscript.global
    Cossacks 3/mods/NavalRamming/data/scripts/units/unit.inc/initial.inc
    Cossacks 3/mods/NavalRamming/data/scripts/units/unit.inc/nothing.inc

**Важно:** до копирования удали или отключи старый диагностический файл mods/NavalRamming/data/scripts/lib/miscext.script (только в папке мода, не оригинальный скрипт игры). Генератор не удаляет его автоматически.

## Тест

1. Сначала сохрани резервную копию своих сохранений и папки мода.
2. Используй **новую офлайн-карту**, не загружай старые сохранения, отключи другие моды.
3. Создай 2 вражеские галеры и отключи мирный режим.
4. Направь галеру в другую и наблюдай HP обоих кораблей. Ожидается HIT при выполнении условий и уменьшение HP (штатная защита влияет на итоговый урон).
5. Для разгона используй фрегат, линейный корабль и яхту: дай длинный маршрут с места; сравни начальную скорость и скорость после разгона. После остановки начни снова.
6. В игровом логе ищи NavalRamming INIT, NavalRamming FULL_SPEED, NavalRamming HIT.

При ошибке компиляции или необычном поведении отключи мод и приложи лог.

## Ограничения / риски

- Включение двух новых полей TObj (navalSpeedFraction, navalLastRamTime) меняет сериализуемую структуру. **Совместимость старых сохранений и повторов не тестировалась.** Не использовать в мультиплеере.
- Частота проверки и единицы времени зависят от движка: 5 единиц игрового времени могут не равняться 5 реальным секундам.
- Определение тарана приближённое: по радиусам и направлению движения, НЕ по физическому импульсу, не учитывает относительную скорость цели.
- В этой итерации урон может оказаться слишком высоким или низким; собираем первые игровые замеры.
- В этом прототипе урон тараном наносит только галера; инерционный разгон охватывает все стандартные водные типы. Расширение тарана на фрегаты и другие корабли будет после подтверждения теста.
- Рампа MoveStep=0.03 рассчитана для штатных типов на основе их текущих файлов .prop; несовместима с модами, меняющими MoveStep.
- Не публикуй сгенерированные игровые оригиналы в публичном репозитории; оставляй их локально.
