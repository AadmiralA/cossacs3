# NavalRamming v7 — разные темпы разгона

Основа: работавшая в игре v6. Изменена только формула разгона и добавлены маркеры диагностики. Урон от тарана галер и 5 единиц игрового времени перезарядки из v6 сохранены.

## Время разгона до штатного максимума (игровое время)

| Тип | Время от 35% до 100% |
| --- | ---: |
| galley | 4 |
| frigate | 6 |
| battleship | 8 |
| chaika, yacht, yachttur | 4 |
| xebec | 6 |
| ferry | 8 |
| fishboat | 5 |
| Неизвестный водный тип | 5 |

Формула для движения: navalSpeedFraction := Clamp(navalSpeedFraction + MaxFloat(0, deltatime) * 0.65 / navalAccelTime, 0.35, 1.0). При остановке доля движения сбрасывается к 0.35. Штатное значение MoveStep=0.03 остаётся верхним пределом. Реалистичного выбега после отмены движения **пока нет**: движение может остановиться сразу.

## Установка

Работа ведётся в ветке feature/naval-ram-experimental.

В Git Bash из папки репозитория:

    git switch feature/naval-ram-experimental
    git pull --ff-only origin feature/naval-ram-experimental
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./tools/build_experimental_naval_v7.ps1

Скопировать все **три** сгенерированных файла по соответствующим путям в mods/NavalRamming/:
- mod/data/scripts/dmscript.global
- mod/data/scripts/units/unit.inc/initial.inc
- mod/data/scripts/units/unit.inc/nothing.inc

Не удалять и не редактировать оригинальные файлы игры. При переходе с v6 заменить два .inc; dmscript.global оставлен в составе сборки.

## Проверка

1. Новая одиночная карта с одной галерой, одним фрегатом и одним линейным кораблём.
2. По очереди давать им достаточно длинную прямую команду движения.
3. В новом логе искать NavalRamming ACCEL_START, ACCEL_50, ACCEL_75 и FULL_SPEED с именем корабля и t=... . Сравнивать FULL_SPEED.t - ACCEL_START.t для каждого типа; ожидается примерно 4 / 6 / 8 единиц игрового времени (погрешность игрового тика и возможных остановок).
4. Для проверки неизменности тарана разместить две вражеские галеры и искать NavalRamming HIT.

## Оговорки

- V7 рассчитана на стандартный MoveStep из reference/objects/ref/refunit.prop; другие моды, меняющие MoveStep, не поддерживаются.
- Это плавный разгон в штатном механизме перемещения, а не физическая динамика корпуса или сохранение импульса при остановке.
- Игра ещё не запускалась с v7. Старая v6 сохранена отдельным генератором build_experimental_naval_v6.ps1 для отката.
- Старые сохранения, реплеи и мультиплеер не проверены: dmscript.global меняет структуру TObj.
- Таран v6 пока может срабатывать повторно при одном продолжительном контакте после восстановления перезарядки; защита до физического разъединения — отдельная будущая правка.
